# lhg-bp-review：投资人视角自检方法论

> 目标：写完 BP 后，用投资人的眼睛重读一遍。本 skill 是 BP 发出前的最后一道门。
> 核心纪律：**先跑确定性审计（机器），再过四问清单（人）；blocker 不清零不许发出**。

## 1. 何时使用

- `/lhg-bp:bp` 的 Phase 2 → 全程按本 skill 执行
- `/lhg-bp:bp-audit` → 步骤 2 的人工部分
- `/lhg-bp:bp-pitch` → 按第 6 节提炼路演版

## 2. 输入与输出

- **输入**：完整 BP 初稿（Markdown）
- **输出**：体检报告（blocker/warning 清单 + 四问回答）或 10 页路演版
- **不输出**：重写 BP——发现问题打回对应 skill 修，本 skill 只评审

## 3. 步骤 1：确定性审计（机器先行）

运行插件自带的审计脚本（插件目录 `scripts/audit/bp_audit.py`，`--target` 指向 BP 文件）：

- **blocker**（BP-SEC-001 章节缺失）：必须补，不许豁免。缺一章 = 投资人少一分信任。
- **warning** 四类：BP-NUM-001（数字矛盾）、BP-HOLLOW-001（空洞表述）、BP-FIN-001（财务勾稽）、BP-CON-001（缺资金用途）。
- warning 的处理：修；或写一条豁免理由——"为什么这里可以例外"，写不出理由就修。
- **红线**：为清零去改脚本规则或阈值 = 作弊，不许。

## 4. 步骤 2：投资人四问清单（人工）

### 问 1：团队可信度——"为什么是你们能做成？"
- 创始人的过往经历，和这个项目是"相关"还是"硬凑"？（前盒马运营做生鲜 = 相关；前游戏策划做生鲜 = 硬凑）
- 缺关键角色吗？缺了有没有补救计划（顾问/正在招）？
- 团队介绍里有没有注水（"曾任职世界 500 强"但没写岗位）？有就删，注水被发现直接出局。

### 问 2：数据真实性——"每个数字都经得起追问吗？"
- 随机挑 3 个数字，问自己：来源？年份？口径？答不上来 → 标 [待补充] 或删。
- 市场规模数字：TAM/SAM/SOM 三层口径一致吗？和营收预测用的是同一套假设吗？
- 试点数据：样本量、时间范围写了吗？"复购率 60%"不写 n 和时间 = 耍流氓。

### 问 3：逻辑自洽——"这条线算得过来吗？"
- 画出主线：市场规模 → 切入点 → 用户数 → 营收 → 利润，逐环检查数量级。
  - 例：SOM 120 亿的市场，你第 3 年营收 50 亿（40% 份额）？除非你是垄断，否则重算。
- 痛点章的用户 = 市场章切入点的人群 = 产品章服务的对象，三处是同一拨人吗？
- 资金用途 → 里程碑：花的钱和要达到的里程碑对得上吗？

### 问 4：退出路径——"我怎么赚到钱？"
- 写了退出设想吗（并购/IPO）？对标案例是谁（同赛道被并购/上市的公司）？
- 天使轮可以一句话带过，A 轮必须有半页：对标 + 时间表。
- ❌ "我们要做独角兽" → ✅ "对标叮咚买菜路径：区域验证 → 全国复制 → 3-5 年 IPO/并购"

## 5. 体检报告模板

```markdown
## BP 体检报告（<项目名>，<日期>）

### 确定性审计
- blocker：x 个（清单）
- warning：x 个（修/豁免理由）

### 投资人四问
1. 团队可信度：<一句话结论>（证据/缺口）
2. 数据真实性：<一句话结论>（抽查的 3 个数字）
3. 逻辑自洽：<一句话结论>（主线检查结果）
4. 退出路径：<一句话结论>

### 结论
- [ ] 可发出 / [ ] 打回（打回原因 + 对应要修的 skill）
```

## 6. 路演版提炼法（10 页）

完整 BP 是"存档"，路演版是"演讲"。提炼三原则：

1. **删细节不删逻辑**：技术实现、长表格进附录；主线（痛点→方案→数据→要钱）一页不能少。
2. **每页一句话标题**：标题是观点不是名词。"市场规模 5000 亿"→"5000 亿赛道，我们切二线年轻家庭"。
3. **数字只留 3-5 个**：投资人 10 分钟记住的数字不超过 5 个，挑最有杀伤力的。

10 页映射（见 `/lhg-bp:bp-pitch` 命令）：封面 / 痛点 / 方案 / 市场 / 数据 / 模式 / 竞争 / 团队 / 财务 / 融资。

## 7. 路演版逐页检查清单（10 页）

提炼完路演版，逐页打勾：

1. **封面**：一句话说清干什么了吗？有融资轮次/金额吗？
2. **痛点**：场景化吗（有具体的人和事）？用户原话/数据有吗？
3. **方案**：一句话方案 + 3 个以内差异点，每个有事实支撑吗？
4. **市场**：TAM/SAM/SOM 三层 + 切入点，数字带来源吗？
5. **数据**：增长曲线/关键指标，样本量和时间范围写了吗？
6. **模式**：收入公式一句话 + 单体模型，算得过来吗？
7. **竞争**：对手点了名吗？"对手抄你的成本"说清楚了吗？
8. **团队**：每人一句话相关履历，注水删干净了吗？
9. **财务**：3 年关键数字 + 核心假设，假设标了 [试点/对标/估算] 吗？
10. **融资**：金额/出让/用途（百分比）/里程碑/退出路径，齐了吗？

10 页里任何一页答不上来 → 打回对应 skill 重写，不许"先这样"。

## 8. 投资人刁钻问题预演（路演前必练）

找个人扮演投资人，用这 6 个问题拷打创始人，答不上来就别上场：

1. "如果腾讯/美团明天抄你，你怎么办？"（考壁垒）
2. "你的数字里，哪个是最可能错的？"（考诚实，答"都对"直接出局）
3. "上一个类似项目为什么死了？"（考行业认知）
4. "你这个月最大的困难是什么？"（考执行力，答"没困难"等于没干活）
5. "为什么现在是融资的好时机，而不是 6 个月后？"（考节奏）
6. "如果我不投，你 Plan B 是什么？"（考韧性）

## 9. 体检的时间盒（别把评审做成重写）

- 确定性审计：10 分钟。脚本跑完，blocker/warning 清单就有了。
- 四问清单：30 分钟。每问 5-8 分钟，一句话结论，不展开辩论。
- 体检报告：10 分钟。按第 5 节模板填，不许写小作文。
- 总计 50 分钟。超过 1 小时还没结论 → 说明 BP 问题太大，直接打回重写，别在评审会上修 BP。
- 体检报告要存档：下次融资前翻出来，对照看上次的问题修了没有。

## 10. 常见误区（反模式）

- ❌ 审计全绿就直接发出——机器只查格式，四问清单才是投资人视角
- ❌ warning 全写豁免理由——豁免超过 3 条说明 BP 本身有问题
- ❌ 路演版 = 完整版删几页——路演版要重写标题和逻辑，不是删减版
- ❌ 体检报告只写"没问题"——没发现问题的体检 = 没体检，重来

## 11. 自检与反馈

本 skill 使用后：

1. 审计 blocker 清零了吗？→ 没清零不许谈"可发出"
2. 四问每问都有一句话结论吗？→ 没结论就是走过场
3. 体检报告发出去了吗？→ 口头"没问题"不算，书面报告才算
4. 路演版标题连读通顺吗？→ 10 个标题连起来应该是一篇 200 字的短文

反馈渠道：以 `[QC] <一句话问题>` 为标题提交到 https://github.com/lhg-plugs/lhg-bp/issues，
正文写清"场景 → 评审问题 → 期望"。好的路演开场白/收尾话术也欢迎贡献。
