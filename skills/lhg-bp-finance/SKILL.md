# lhg-bp-finance：财务章节方法论

> 目标：投资人不信你的预测数字，但会看你的**假设**。财务章的价值不在数字本身，而在"假设是否合理、逻辑是否自洽"。
> 核心纪律：**每个数字背后必须有一个写出来的假设；假设不许藏**。

## 1. 何时使用

- `/lhg-bp:bp` Phase 1 写财务章 → 全程按本 skill 执行
- `/lhg-bp:bp-audit` 报 BP-FIN-001（勾稽矛盾）→ 按第 5 节排查
- 用户说"财务我不会算" → 用第 3 节的极简算法手把手带

## 2. 输入与输出

- **输入**：项目信息卡（商业模式、收费、单客/单店数据）
- **输出**：财务章三段（假设清单 → 3 年预测表 → 资金用途），Markdown 表格
- **不输出**：完整三张报表——BP 里不需要资产负债表，那是尽调的事

## 3. "假设-预测-资金用途"三段式

### 3.1 第一段：假设清单（先写假设，再算数字）

假设分三类，每类写 2-4 条，每条一句话 + 依据：

- **规模假设**：第 1/2/3 年做到多少用户/店/单？依据：切入点城市容量、团队扩张速度。
  - ✅ "第 1 年开 40 个仓：依据是单城市模型已验证，团队每季度能开 10 个"
  - ❌ "第 3 年开 1000 个仓"（无依据的指数增长）
- **单体假设**：单个用户/店贡献多少收入？毛利率多少？依据：试点数据或对标公司。
  - ✅ "单仓月均 GMV 180 万（试点仓 2026 年 6-9 月实际 176 万）"
- **费用假设**：费用率多少？何时打平？依据：对标公司的费用结构。

**假设的诚实分级**：每条假设标 [试点数据]/[对标]/[估算]。全是 [估算] 的财务章 = 讲故事，先回去跑数据。

### 3.2 第二段：3 年预测表（只放关键行）

|  | 第 1 年 | 第 2 年 | 第 3 年 |
|---|---|---|---|
| 营收 |  |  |  |
| 毛利率 |  |  |  |
| 费用率 |  |  |  |
| 净利润 |  |  |  |
| 关键驱动（如开仓数/付费用户数） |  |  |  |

- 表下必须跟一句："以上基于第 3.1 节假设，关键变量是 X（如开仓速度），X 每慢 1 个季度，营收下修约 Y%。"
- **勾稽自查**：营收 − 成本 = 利润，每行自己先算一遍（审计 BP-FIN-001 会抓，丢人不如先自查）。
- 口径统一：营收是 GMV 还是实收？利润是毛利还是净利？全文只用一种，表头写清。

### 3.3 第三段：资金用途（钱怎么花）

- 格式：研发 x% / 市场 x% / 团队 x% / 开仓 x% / 备用金 x%，加起来 =100%。
- 每个用途跟一句"花完达到什么里程碑"（如"开仓 35% → 新增 40 个仓"）。
- ❌ "融资 2000 万"之后没下文 → ✅ "2000 万：研发 40%、开仓 35%、市场 15%、备用金 10%，18 个月做到 40 仓、月营收 7000 万"

## 4. 单位经济模型（A 轮/Pre-A 必备，天使可选）

- **单客模型**：获客成本 / 首单金额 / 复购率 / 年贡献 → 一句话结论"第几个月回本"。
- **单店模型**：单店投入 / 月均 GMV / 回本周期 → 一句话结论"模型可复制吗"。
- 写不出单体模型 → 说明商业模式还没想清楚，打回 lhg-bp-structure 第 3.3 节重写商业模式章。

## 5. 极简测算示例（手把手）

假设一个社区生鲜前置仓项目（数字均为示例，教你方法）：

**步骤 1：定单体**
- 单仓月均 GMV 180 万（试点实际 176 万，取整）[试点数据]
- 毛利率 22%（试点 21.5%，对标叮咚 20-25%）[试点数据+对标]
- 单仓月费用 28 万（人力 15 万 + 租金 8 万 + 其他 5 万）[试点数据]

**步骤 2：算单仓利润**
- 月毛利 = 180 万 × 22% = 39.6 万
- 月净利 = 39.6 万 − 28 万 = 11.6 万 → 单仓 12 个月回本（投入约 140 万）

**步骤 3：外推 3 年**
- 第 1 年 40 仓 → 年营收 = 40 × 180 万 × 12 = 8.64 亿（保守按 8.6 亿）
- 第 2 年 70 仓、第 3 年 100 仓，同口径外推
- 总部费用另计：每年 3000 万（研发+管理）[估算]

**步骤 4：写敏感性**
- "关键变量是开仓速度：每慢 1 个季度，第 1 年营收下修约 2 亿。"

看懂了吗？财务章 = 单体模型 × 扩张速度，每一步都有依据。这就是投资人要看的东西。

## 6. 分轮次财务详略

- **天使轮**：1 页。假设清单（5-8 条）+ 1 年预测（营收/毛利/费用三行）+ 资金用途。别做 3 年表，做了也没人信。
- **Pre-A**：2 页。3 年预测表 + 单体模型 + 敏感性一句话。投资人要看"模型跑通了吗"。
- **A 轮**：3 页。Pre-A 内容 + 月度拆解（前 12 个月）+ 对标公司财务对比。投资人要看"规模化后还赚钱吗"。

轮次错配的后果：天使轮甩出 5 年精确到个位的预测 → 投资人觉得你不懂行；A 轮只有 1 页假设 → 觉得你没算过账。

## 7. 财务章四种死法（自查）

1. **假设隐身**：只有数字没有假设 → 投资人默认你在编。
2. **增长拍脑袋**：每年翻 3 倍，无依据 → 改成"基于单体模型的线性外推"，慢但可信。
3. **口径漂移**：第 1 年用 GMV、第 3 年用实收 → 全文统一，表头注明。
4. **用途缺失**：融了钱不知道花哪 → 审计 BP-CON-001 会抓，先自己补上。

## 8. 投资人常问的财务问题预演（提前准备答案）

财务章写完，把这 5 个问题先自问一遍，答不上来就回去补：

1. **"你的单体模型，样本量是多少？"** —— 试点 1 个仓的数据就敢外推 100 个仓？诚实回答样本量，并说明"规模化后单体可能被摊薄/优化"。
2. **"毛利率 22%，对标是谁？"** —— 说出 1-2 家对标公司的公开毛利率，证明你的数字在行业区间里。
3. **"什么时候打平？打平前要烧多少钱？"** —— 这是融资额的依据：烧的钱 = 融的钱，算给投资人看。
4. **"如果增长只有预测的一半，还活得下去吗？"** —— 准备一句："减半情景下，第 18 个月现金流为正，靠现有资金可支撑 24 个月。"
5. **"这笔钱为什么是 2000 万不是 5000 万？"** —— 金额必须和里程碑挂钩："2000 万对应 40 个仓的投入，5000 万我们花不完，花不完的钱会稀释创始人股份。"

## 9. 数字的写法规范（细节决定可信度）

- 单位统一：全文用"亿"或"万"，不许一会儿"5000 万"一会儿"0.5 亿"。
- 精度克制：预测数字保留 1 位小数足够，"8.64 亿"不如"约 8.6 亿"——过度精确显得假。
- 百分比必带基数："复购率 61%"后面跟"（试点 200 户，2026 年 6-9 月）"，没基数的百分比 = 耍流氓。
- 货币必带币种：涉及出海/美元基金，"2000 万"写成"2000 万人民币"。
- 时间必带年份："去年"改成"2025 年"，BP 会被翻出来看很多次，"去年"会过期。

## 10. 常见误区（反模式）

- ❌ 预测做到第 5 年精确到个位——3 年之后都是玄学，精确显得不专业
- ❌ 毛利率 80% 的生鲜/零售项目——对照行业常识，离谱的数字先解释
- ❌ "保守估计"但数字激进——投资人看的是数字不是形容词
- ❌ 资金用途写"补充流动资金 100%"——等于没说，拆细
- ❌ 利润表和市场规模用两套假设——TAM 5000 亿的市场，你第 3 年营收 500 亿？审计 BP-NUM-001 + 投资人都会问

## 11. 自检与反馈

财务章写完后：

1. 每条假设标了 [试点数据]/[对标]/[估算] 吗？→ 没标就是藏假设
2. 营收 − 成本 = 利润，自己验算过吗？→ 插件审计脚本会验算，先自己来
3. 资金用途百分比加起来是 100% 吗？→ 顺手算一下
4. 关键变量的敏感性说了一句吗？→ "X 慢 1 个季度，营收下修 Y%"，有这句可信度翻倍

反馈渠道：以 `[QC] <一句话问题>` 为标题提交到 https://github.com/lhg-plugs/lhg-bp/issues，
正文写清"轮次 → 财务问题 → 期望"。好的单体模型模板（如 SaaS/零售/硬件）也欢迎贡献。
